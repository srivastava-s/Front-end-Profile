# Front-end Profile – Shashank Kumar Srivastava

Static portfolio site focused on frontend and UI engineering work: React projects, Chrome extension interfaces, dashboards, and AI‑powered productivity tools.

## Stack

- HTML5
- CSS3 (custom, responsive layout)
- Vanilla JavaScript (navigation + smooth scroll)

## Getting started

```bash
git clone https://github.com/srivastava-s/Front-end-Profile.git
cd Front-end-Profile
```

Open `index.html` directly in your browser, or serve it with any static HTTP server.

## Customization

- Update sections in `index.html` to reflect new frontend projects or roles.
- Adjust visual styles in `styles.css`.
- Enhance interactions and animations in `script.js`.
